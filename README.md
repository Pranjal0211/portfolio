# Pranjal Sharma — Portfolio

My personal portfolio site: projects, experience, education and skills.

Built with plain HTML, CSS and JavaScript — no framework, no build step.

## Run locally

Open `index.html` in a browser.

## Structure

- `index.html` — page content
- `styles.css` — design tokens, layout and responsive styles
- `script.js` — mobile menu, scroll reveals, project filters, skills tabs
- `images/` — photos used on the site
